## Introduction

In this project, we have extended an existing Pascal grammar to support Delphi-style object-oriented programming. Following features have been implemented in this project.

*   Classes and Objects
    
*   Constructors and Destructors
    
*   Encapsulation
    

## Resources Used

*   Pascal Grammar (Base Grammar Provided taken from pascal.g4)
    
*   Delphi Reference  (to create classes and objects for delphi syntax reference)
    
*   Java & ANTLR Runtime  (to interpret the grammar generated by antlr)
    

## Implemented Features

### 1\. ANTLR4 Grammar for Delphi

We extended the base Pascal grammar to support object-oriented programming. This includes:

*   Class definitions
    
*   Object instantiation
    
*   Constructors and destructors
    
*   Visibility modifiers for encapsulation (public, private, protected)
    

### 2\. Java Interpreter

A Java interpreter was developed to:

*   Parse the abstract syntax tree (AST) generated by ANTLR
    
*   The interpreter acts as a grammar explorer, traversing the Abstract Syntax Tree (AST) generated by the ANTLR parser.
    
*   Identifies key language constructs: It recognizes class declarations, record declarations, method declarations (functions, procedures, constructors, destructors), and variable declarations.
    

*   Extracts relevant information: It extracts the names of classes, records, methods, and variables, along with their types and parameters.  
    Prints the extracted information: It outputs this information in a structured format to the console, providing a clear view of how the grammar has parsed the code."
    

  

### 3\. Input and Output Functionality

We implemented support for integer input and output using:

read(x); to take integer user input from the console  
print(x); to output the string value to the console

## How to Run the Code

### 1\. Generate ANTLR Lexer and Parser

  
  

```java -jar antlr-4.13.2-complete.jar Delphi.g4 -Dlanguage=Java -visitor```

  

```javac -cp antlr-4.13.2-complete.jar \*.java```

  

### 2\. Run the Interpreter

  

```java -cp .:antlr-4.9.3-complete.jar Main test1.pas  # Linux/macOS```

```java -cp .;antlr-4.9.3-complete.jar Main test1.pas  # Windows```

  

### 3\. Expected Output

The interpreter will parse and execute the provided .pas test files, displaying the expected output on the console.
